## 浏览器验收

复用 `web/scripts/s3-journey.mjs`，通过 `FULL_SITE=1` 执行全站建设验收，不另建应用或重复测试框架。运行命令：

```powershell
$env:FULL_SITE='1'
$env:BASE_URL='http://localhost:PORT'
$env:CHROMIUM_PATH='C:/Program Files/Google/Chrome/Application/chrome.exe'
$env:EVIDENCE_DIR='ABSOLUTE_PATH_OUTSIDE_GIT'
node scripts/s3-journey.mjs
```

验收包含 1440×1000 桌面和 390×844 手机。先走完整上传 → 报告 → Studio → 保存 → 行动完成与恢复，再对全部个人路由、首页、五个主题入口、开始页、说明页、预告页、公开报告和实际生成的公开分享逐页等待内容、字体与图片解码后截图。首屏缩略图和完整页面截图通过本地 `index.html` 联结；`captures.json` 记录每页标题、路由、图片与布局状态。

交互检查包含发型选择与保存、Studio 类别切换、测量选中、风格选择模式、色彩进入 Studio 的参数与选中状态、公开卡片视觉切换、展开内容、设置/调整面板、行动完成刷新保持。深色与减少动态效果仅对建议和 Studio 抽样，不扩展为新的专项。
