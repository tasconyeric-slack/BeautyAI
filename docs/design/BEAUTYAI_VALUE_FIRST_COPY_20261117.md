# BeautyAI · 价值导向文案 V2 / Codex Cloud 实施定稿

**日期：2026-11-17 · 产品 Owner 已认可方向 · Issue #92 · Draft PR: Codex 实施入口**

## 目标和内容优先级

让用户在第一屏明确知道：**BeautyAI 能帮我认识自己的外貌特点、发现值得保留的优势，并把建议落实到实际造型决策。**

核心能力按价值排序：颜值评分与参考样本中的位置 → 五官/脸型与面部比例的理解 → 适合自己的造型方案和具体行动 → 可保存、可复看的完整形象报告。Look Studio / 发型模拟目前不是成熟主卖点；降低首页展示篇幅，保留产品入口与现有功能。

**文字风格：** 直接、克制、有审美、有用户价值；不要低价值的功能清单、空泛人生哲学、反复的免责声明和技术实现说明。一个页面原则上只讲一次同一件事。营销标题可以有情绪，但正文必须让用户知道具体获得什么。

页面上的真实案例展示优先顺序：

### 03 FIND WHAT WORKS FOR YOU / 个性化建议

**语气示范，不作为虚构样例事实直接上线：**

## 首页删减/归并的明确决定

| 当前页面元素 | 执行动作 |
| --- | --- |
| Hero 后独立 manifesto「先了解自己的特点…」 | 删除独立模块；价值已由 Hero 讲清 |
| 「一张脸，慢慢读懂」 | 改为实质面部分析模块，保留真实测量肖像与交互中有价值的部分 |
| 「不同的脸，有不同的风格选择」+ 人像拼图 | 删除大段说明或转成非常轻量的视觉过渡；不再占核心内容位置 |
| 大幅发型对比、LOOK STUDIO 完整交互/故事 | 从首页主线撤下或压成极小、低优先级入口；不要删除真实 /studio/相关页面功能与资源 |
| 「你的评分、分析与建议，整理成一份报告」 | 重写为「一份报告，找到属于你的变美方向」以及三项真实可感知价值 |
| 「观察→解读→建议」「选择→比较→保存」的重复流程列表 | 只在产品实际操作环节保留必要的过程提示 |
| 「保持现在，也是一种选择」「改变多少，由你决定」等反复自我保护口号 | 从首页营销区移除 |
| 技术原理、计数、模型名、过度边界说明 | 不应出现在营销区；只在用户做决定必需的结果/上传相关位置简洁呈现 |

页面要更短，设计不一定更“空”：优先用现有的真实测量、人像、报告内容作为视觉证据，而不是大篇幅文字。

## 报告页与免费结果页的同步优化

1. **免费结果页**：先清楚显示真实颜值评分、真实可用的参考样本排名、代表性面部观察，然后告诉用户完整报告能解决什么问题。付费信息（¥139、权益范围）保持准确、清晰、易发现；不变成防御性付费解释，也不隐藏必要交易信息。
2. **完整/示例报告首页**：帮助用户优先回答三问：**我的优势是什么？什么风格更适合？下一步怎么做？** 长测量表、原始数字和辅助方法论可折叠或置后；数据本身仍保留可访问。
3. **具体建议卡片**：优先标题「推荐改变 / 为什么适合你 / 怎么做」；不要为同一建议连续堆叠「依据、限制、如何核验、你可以自行选择」等重复字段。若用户确实需要摄影质量/证据来源，保留适度查看途径。
4. **摄影、可靠性与模型边界**：上传页保留必要照片指导与处理同意；模型预测结果显示必要的简短样本/估计说明（排名是具名参考照片样本中的位置，不是全人群审美判决），无需在多处重复。
5. **不一致修正**：如真实样例同一推荐前后对发型长度、配色等给出互相矛盾的文字，仅根据真实结构化报告证据修正呈现，禁止把源数据问题用营销文案掩盖。

## Codex 实施范围、验收与退出条件

**生产入口：** web/app/page.tsx → web/components/home/homepage.tsx → web/components/design-motion/design-motion.tsx + web/components/home/hero.tsx。样例页面 web/app/report/sample/page.tsx。关联文案：web/lib/copy/zh.ts、web/components/report/{free-report.tsx,full-report.tsx,report-overview.tsx,sample-report.tsx}；只在必要时更改 profile 组件与 CSS。

**必须保留：** 成熟的摄影设计系统/颜色/字体/动效，真实的 P002 面部测量画面，P001 独立公开示例身份，既有数据与模型可信度、已授权排名边界、隐私处理同意、照片删除、¥139 付费、Studio 入口/功能、来源参数、工作中结果页。

**不要碰：** API/ML/Ridge/排名统计/数据集/模型参数/schema/支付流程/隐私保存与授权/环境变量/部署/品牌名。避免全站无关审计，不为纯文案增加新依赖。

**完成标准：**
- 1440px 桌面和 390px 手机：首屏可读，CTA 清晰，四个价值模块有合理视觉节奏。
- 首页→开始测评、首页→示例报告、免费结果→完整报告/解锁等既有关键路径仍可达。
- 所有示例数字、面部特征和建议来自对应本人真实样例，不混 Person-001 与 Person-002 的数据。
- 没有虚假“免费完整报告”暗示，保留短而必要的样本范围/同意/付款信息，不重复防御。
- 更新受影响的现有前端测试，执行 TypeScript / targeted Vitest / Next build，完成一次关键路径可视化确认；最多一轮有针对性的修正。
- **同一 PR 一次交付**：说明删除了什么、保留了什么、关键图文前后变化、测试结果；CI + Codex review 完成后按仓库策略处理。

文案有轻微排版、长度调适空间，但**不重新发明主张和叙事**，不等用户再次批准细枝末节。
